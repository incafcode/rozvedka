Ищет бизнес без сайта или с шаблонной страницей: QR-меню, запись, каталог

Где искать

Где взять: зарегистрируйтесь в Менеджере Платформы 2ГИС → «Главная» → «Создать демо-ключ» — бесплатно, один раз: месяц и 1000 запросов. Дальше — подписка с Places API (пакет 10 000 запросов в месяц — около 6 700 ₽). Телефоны и сайты мест 2ГИС отдаёт только ключам с доступом к контактам — его подключает отдел продаж 2ГИС (заявка). Без него найдутся места без сайта: название, адрес, рейтинг, ссылка на карточку 2ГИС, где виден телефон. Ключ хранится на сервере Rozvedka зашифрованным, на этом компьютере его нет.

Города

Пишите по-русски — название само переведётся на украинский, как в Google Картах. Можно несколько через запятую.

Категории

Выберите сферу и отметьте готовые категории (синонимы склеены, тип Google подставится сам) или впишите свою. В Google уходит запрос «категория в городе».

Параметры

Тонкая настройка: пауза и цена запроса

Пауза — между страницами одного запроса. Актуальную цену смотрите в Google Cloud → Billing.

Признаки шаблонного меню

Если адрес сайта содержит один из признаков — это тёплый лид. Любой другой сайт считается собственным, и заведение скрывается.

Исключить по названию

Заведения с этими словами в названии не попадут в выдачу.

    Помощники

    ИИ сам находит в отзывах Google одну зацепку («хвалят рибай», «долго ждать по выходным») — сообщение выходит конкретнее. Отзывы загружает сервер Rozvedka: один запрос из лимита поиска Google на заведение, один раз.

    ИИ смотрит на каждое заведение в списке Парсера и ставит 1–5: насколько ваше предложение им нужно, с причиной. Сортировка «Сначала перспективные» это учитывает: в разбивке процента «ответят» у неё пометка «ИИ». Один запрос на заведение, до 40 за раз.

    Пришёл ответ — ИИ подскажет: «похоже, интерес → перевести в „Заинтересован“», «спрашивают цену → ответить ценой». Сам ничего не меняет.

    Без ключа — через чат с Claude

    Бесплатно в рамках подписки claude.ai. 1) Скопируйте запрос. 2) Вставьте его в чат с Claude. 3) Скопируйте ответ целиком и вставьте ниже — тексты разложатся по карточкам.

    Демо по нишам

    Готовые примеры под рукой. Если ниша лида совпала по словам (категория или название), первое сообщение упоминает готовый пример, а ссылка уходит в ответе после «так». Строки проверяются сверху вниз. Личное демо из карточки лида важнее.

    Какие тексты отвечают

    Сколько отправлено и сколько ответили по каждому варианту текста. Ответ засчитывается сообщению, после которого он пришёл.

    База

    Всё, с чем вы уже работали. Выберите раздел — список откроется справа на всю страницу. «В работе» — лиды по стадиям, клик открывает карточку. «Стоп» — кому не пишем: в поиске они больше не появятся.

    Отчёт по воронке

    Клавиши

    Под левую руку — правая остаётся на мыши. Наведите курсор на карточку или откройте лида и жмите. Раскладка не важна: S и Ы — одна клавиша.

    Вид

    «Графит» — чёрная сцена, угольные карточки и шрифт Inter, «Красная» — как было. Кнопки: «Стекло» — как было, «Плоские» — заливкой, «Контур» — круги с рамкой, «Тихие» — одни значки. Карта — улицы вокруг заведения, бесплатно, при наведении проявляется в цвете; нужны координаты места (их записывает поиск). Фон окна выбирается ниже.

    Наборы

    Набор ставит фон, цвет, яркость, плотность и скорость разом.

    Фон окна

    У Базы и ленты сообщений может быть свой фон — по нему сразу видно, где вы находитесь.

    Цвет

    «Красный» — под цвет программы, «Родной» — как фон задуман автором, «Свой» — один из восьми тонов для любого фона.

    Кнопки, выделение, полоска прогресса и заголовок окна берут цвет у фона. С «Красным» ничего не меняется.

    Насколько боковая панель, шапка и карточки закрывают фон: меньше — фон просвечивает сильнее, больше — текст читается спокойнее.

    Качество

    Поведение

    Во время поиска фон ярче и быстрее. Вспышка цветом события:

    Если ничего не трогать, интерфейс гаснет и остаётся только фон. Любое движение мыши или клавиша возвращают всё обратно. Во время поиска не включается.

    Без анимации фон застывает и не реагирует на курсор. Без стекла кнопки не преломляют и не размывают фон.

    Сила стекла

    Панель лида, меню, уведомления и шапка — матовое стекло над фоном, кнопки — «жидкое». Слабо — плотнее и спокойнее, сильно — фон виден ярче. На качестве «Низкое» стекло выключается само.

    Обо мне

    Имя, регион и цена — в «Профиле»: там же они хранятся в учётке и заполнятся сами на новом компьютере.

    Подставляется во все тексты программы: шаблоны, быстрые ответы, скрипт звонка, правила для ИИ.

    В своих шаблонах и ответах можно писать {имя} {регион} {цена} — подставятся сами.

    От страны зависят номера телефонов (как читать «067…» или «8 (916)…», какие из них мобильные — для кнопок Telegram, Viber, WhatsApp), язык и регион поиска Google и город из адреса. Автоперевод названий на украинский — только для Украины. Язык сообщений (черновики, шаблоны, готовые ответы, скрипт звонка, правила для ИИ) по стране: Украина — украинский, остальные — русский; можно выбрать любой из списка или «Свой язык…» — на нём ИИ пишет заведениям, программа остаётся на русском. После смены языка окно перезагрузится.

    Доступ

    Хранится только на этом компьютере. В Google Cloud Console ограничьте ключ одним API — «Places API (New)».

    Соцсети

    Сначала читаем сайт или шаблонное меню заведения и его страницы «контакты / оферта» — оттуда соцсети, доп. номера, почта и продавец (ФОП или ТОВ из реквизитов). Если Instagram там нет, ищем «название + город + instagram». Найденный профиль сверяем по его превью: совпали название и город — подтверждён сам, иначе помечен точкой — откройте и проверьте.

    Дожимы
